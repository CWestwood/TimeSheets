Leave Schedule
  • Col A — Name
  • Col B — Leave type
  • Col C — Start date
  • Col D — End date
Call Roster
  • Col A — Date
  • Col C — OT start time
  • Col D — OT end time
  • Col E/F/G — On-call names
  • Col H — Standby name
Public Holidays
  • Col A — Holiday date
